# SWE 4301: Object Oriented Concepts II

Welcome to the course site for **Object Oriented Concepts II**.

## Course focus

This course develops practical techniques for designing, testing, and maintaining object-oriented software. We will revisit the foundations of object-oriented programming and use them to reason about code structure and software quality.

## Topics

- Abstraction and identifying concepts in a problem domain
- Code smells and refactoring
- Unit testing
- SOLID principles and separation of concerns
- Collaboration with version control systems such as Git
- Type systems, reflection, generics, and annotations

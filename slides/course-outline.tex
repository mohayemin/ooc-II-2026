\begin{frame}[allowframebreaks]{Main topics we will cover}

    \begin{enumerate}
        \item OOP basics - a revisit
        \item Abstraction - Identifying "concepts" and naming them 
        \item Code smells - recognizing bad code
        \item Refactoring - fixing bad code without changing its behavior
        \item Unit testing - writing tests to verify your code works as expected
        \item SOLID principles - writing code that is easy to maintain and extend
        \item Separation of concerns - organizing as per the responsibilities of each component
        \item Collaboration using VCS - using source control (e.g., Git) to collaborate with others
        \item Type systems - understanding how type systems work and how to use them effectively
        \item Misc topics - Reflection, Generics, Annotations, etc.
    \end{enumerate}
\end{frame}
